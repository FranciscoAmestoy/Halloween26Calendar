# 🎵 Carpeta de Audio / Sound FX

Coloca aquí tus archivos de sonido en formato `.mp3` para personalizar la atmósfera del Cementerio.

### Archivos reconocidos:
1. **`ambient.mp3`**: Música o sonido ambiental en loop (viento de cementerio, campanas lejanas, cuervos, etc.).
2. **`hover.mp3`**: Efecto al pasar el cursor (hover) por encima de una lápida (susurro espectral, resonancia de piedra, viento fino).
3. **`click.mp3`**: Efecto al hacer clic en una lápida (golpe de losa de piedra, crujido gótico, portazo de cripta).

> **Nota:** Si alguno de estos archivos no está presente o no se encuentra, el juego utiliza automáticamente un sintetizador de audio procedimental por software (**Web Audio API**) como respaldo, garantizando que nunca se quede en silencio durante tus pruebas.
